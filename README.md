I’m excited to share my latest project: Edulk LMS, a fully-featured, secure, and modern platform for digital learning, administration, and collaboration. Built with HTML, CSS, Bootstrap, PHP, and JavaScript (latest versions), this system has been thoroughly tested to ensure quality, responsiveness, speed, and user-friendliness.

👥 User Roles & Key Features
1. Guest Access

	🎬 View public videos uploaded by admins or lecturers 

	📄 Browse downloadable materials semester-wise and category-wise (e.g., subject, week, lecture notes,shortnotes, passpapers)

	🛑 Guests cannot download files; registration required for downloads

	🗂️ Resource details displayed professionally:

		Title | Category | Type | Uploaded | Uploader (name, role) | Status | Actions(Download-Disabled)

2. Admin

	🏠 Dashboard:

		   Latest 20 user logs Summaries of Admins lectures, students, batch representatives displayed card-style

	📊 Logs & Analytics:

		  View all activity, including student, lecturer, and admin logs

	👤 User Management:

		 Add/manage admins, lecturers, batch reps, students

		 Full control accounts: activate, edit, disable, account reset, delete

		 Modern card-style interface, real-time updates

		 system users birthday notification (notification oes to admins and bithday user) and auto generate modern birthday card can download image

	🎓 Lecturer Assignments:

		Assign subjects to lecturers

		Validate for duplicate assignments

		Edit or delete subject assignments

	📚 Course & Resource Management:

		Add/edit/delete subjects (subject code, name, semester, description)

		Upload files with multi-file support, progress bars, success/fail notifications

		View uploaded resources with semester/subject/week/category filter

		Actions: activate, disable,edit, delete
		(Admin have Full Access Manage All Resources)

	📅 Zoom Meetings:

		Paste invitation → auto-extract → schedule meetings

		Auto-disable expired meetings

		Add meeting resources (files, links) Can All Resourses (Active-Disable,Delete Actions)

		Live chat section Avalable for Every Meeting 

		Track upcoming and live meetings(Admin have Full Access Join Every Meeting ,Manage All)



	🎥 Lecture Recordings:

		Upload videos with title, description, type, access level, thumbnail, student view limit

		Manage uploaded recordings (edit, disable, delete)(Admin have Full Access  Meeting All Uploaded Recordings)

		Track views and downloads in real time

		Students/guests only see active, authorized videos

	🗂️ My Drive:

		Private cloud storage for each user (1GB, adjustable)

		Upload all file types with progress bars

		Intelligent display of files with thumbnails/icons

		Live update of used storage

	📝 Reviews & Reports:

		Receive messages/reviews from all users (admin sees unread status)

		Reply to users; users can view admin response

		Attach up to 5 images and links

3. Lecturer

	🏠 Dashboard: Summary of students, batch reps, latest logs

	🎓 Manage Students & Batch Reps: Activate, edit, disable, delete, view details

	📚 Course Content: Add/manage subjects, upload/downloadable materials 

	📄 Resource Upload: Supports images, documents, zip, and multi-file uploads with progress tracking

		(only can manage (Active,Disable,Delete)  currect lecture uploaded materials only.another actions are disabled)

	📅 Zoom Meetings: Schedule/manage meetings with auto-expiry, resource uploads, live chat

	🎥 Lecture Recordings:

		Upload/manage videos with access control (public, batch-only, private)

		Add resources to videos (documents, links)

		Only lecturer can edit/delete/disable their own uploads and resourses only

	🗂️ My Drive: Private 1GB cloud storage per lecturer

	📝 Reviews & Reports: Send messages/reports, view admin replies

4. Batch Representative

	🏠 Dashboard: Students summary and latest logs

	👥 Manage Students: View, edit, activate account

	📚 Course Content: Access subject material and resources (view-only)

	📄 Resource Access: View uploaded files semester/subject/week-wise

	📅 Zoom Meetings:

		See upcoming/live meetings

		Join active meetings via modern interface

		Access meeting resources and live chat

	🎥 Recordings: Watch videos securely (IDM/FDM,... download blocked)

	🗂️ My Drive: Private cloud storage

	📝 Reviews & Reports: Send messages/reports, receive admin replies

5. Student

	📚 Course Access: View subjects, lectures, and resources semester-wise

	📄 Uploaded Materials: View-only access to all files

	📅 Zoom Meetings: Join meetings, access resources, chat with participants

	🎥 Lecture Recordings:

		Watch videos with modern interface

		Video materials accessible below video player

		Download blocked using advanced security (IDM/FDM ,.. download blocked)

	🗂️ My Drive: Private 1GB storage, upload/download/manage files

	📝 Reviews & Reports: Send feedback, messages, attach images/links, view admin replies

⚡ Technical Highlights

	Fully responsive across all devices

	Modern, optimized UI with fast loading and user-friendly navigation

	Real-time updates for videos, views, downloads, drive usage, and logs

	Role-based access control with secure permissions

	Multi-file upload with progress tracking and notifications

	Anti-download protections for videos and secure playback
